# Deploy on Vercel (about 20 minutes)

You create **two Vercel projects from the same GitHub repo**:

| Project | Root directory | What it is | Example URL |
|---|---|---|---|
| `seo-audit-api` | `backend` | FastAPI crawler + audit engine (Python) | `seo-audit-api.vercel.app` |
| `seo-audit-agent` | `frontend` | Next.js dashboard; its `/api/*` proxies to the backend | `seo-audit-agent.vercel.app` ← **the link you share** |

```
Browser ──► seo-audit-agent.vercel.app/api/* ──(adds secret key)──► seo-audit-api.vercel.app/api/*
             checks access code                                      crawls · scores · Claude
```

## Before you start: make two secrets

Make up two long random strings, e.g. with a password manager:

- `BACKEND_SECRET`: shared between the two projects (users never see it)
- `ACCESS_CODE`: what you and your team type into the dashboard to run audits

## Step 1: Backend project

1. Go to vercel.com → **Add New… → Project** → import `pettikadaionline-del/seo-audit-agent`.
2. **Project name:** `seo-audit-api`
3. **Root Directory:** click *Edit* → choose `backend`.
4. **Framework Preset:** FastAPI (it should auto-detect; if not, pick *Other*).
5. **Environment Variables**:

   | Name | Value |
   |---|---|
   | `SEO_API_KEY` | your `BACKEND_SECRET` |
   | `ANTHROPIC_API_KEY` | your Claude API key (from console.anthropic.com). Optional: without it you get rule-based summaries |
   | `SEO_PAGESPEED_API_KEY` | optional, free key from Google Cloud for Lighthouse data |

6. **Deploy.**
7. **Settings → Functions → Function Max Duration:** set **60** seconds (or higher if your plan allows) → Save → *Deployments → ⋯ → Redeploy*.
   Audits take 20–50 s; a short default duration will cut them off.
8. Open `https://seo-audit-api.vercel.app/api/health`. It should show `{"status":"ok",...}`.

## Step 2: Frontend project

1. **Add New… → Project** → import the same repo again.
2. **Project name:** `seo-audit-agent`
3. **Root Directory:** `frontend` · **Framework Preset:** Next.js
4. **Environment Variables**:

   | Name | Value |
   |---|---|
   | `BACKEND_URL` | `https://seo-audit-api.vercel.app` (your backend URL from Step 1, no trailing slash) |
   | `BACKEND_API_KEY` | your `BACKEND_SECRET` (same value as `SEO_API_KEY` above) |
   | `APP_ACCESS_CODE` | your `ACCESS_CODE` |

5. **Deploy.** Open `https://seo-audit-agent.vercel.app`, enter a URL and the access code, then click **Run audit**.

## How it behaves on Vercel

| Setting | Vercel value | Why |
|---|---|---|
| Pages per audit | up to 30 (default 25) | Each step must finish within the function time limit |
| Crawl time budget | 40 s, then it stops and reports what it crawled | Marked "crawl hit page limit" in the dashboard |
| Competitors | up to 3, 6 pages each, inside the same 40 s | |
| Claude effort | `low` | Keeps the AI call short; quality is still good for summarising findings |
| Region | Mumbai (`bom1`) | Faster crawling of Indian sites |
| Saved audits | in the browser (last 10) | Vercel has no persistent disk; export a PDF/JSON to keep one |

All of these are set automatically when the backend detects Vercel. Override any of them with environment variables (`SEO_MAX_PAGES_LIMIT`, `SEO_CRAWL_TIME_BUDGET_S`, `SEO_AI_EFFORT`, …) on the backend project.

## Troubleshooting

| Symptom | Fix |
|---|---|
| "Access code required or incorrect" | Check `APP_ACCESS_CODE` on the frontend project; redeploy after changing env vars |
| "Invalid or missing API key" | `BACKEND_API_KEY` (frontend) ≠ `SEO_API_KEY` (backend) |
| "Audit service is unreachable" | `BACKEND_URL` wrong or has a trailing slash |
| Audit times out (504) | Check step 1, item 7 (Max Duration ≥ 60 s on **both** projects), then lower max pages, remove competitors, or set `SEO_CRAWL_TIME_BUDGET_S=30` |
| AI summary says "Generated by: heuristic" | `ANTHROPIC_API_KEY` missing or invalid on the backend project |
| Backend build fails on Python version | Project Settings → set Python 3.12 (the repo has `backend/.python-version`) |

After setup, every `git push` to `main` redeploys both projects automatically.
